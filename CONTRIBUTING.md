# Contributing plugins

This repository accepts public Olywork plugin manifests, skills, and integration examples.

Do not submit server code, credentials, private provider data, production configuration, or
unreleased catalog pricing. Provider names and logos must follow their own brand guidelines.

Before opening a pull request:

- keep plugin files self-contained and free of secrets;
- update the plugin README when behavior changes;
- include attribution for third-party assets;
- run the repository validation workflow locally where possible.

The public plugin repository is Apache-2.0. Contributions must be compatible with that license.
