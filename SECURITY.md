# Security policy

The public plugins repository must never contain credentials, private endpoints, customer data, or
production configuration. If you find a suspected secret, do not open a public issue with the value.
Revoke the credential first, then report the location privately to the Olywork maintainers.

For vulnerabilities in the hosted Olywork service or private core, use the private contact listed
on [olywork.com](https://olywork.com/) rather than this repository's issue tracker.

Plugin submissions are reviewed for secret exposure and unsafe external instructions before release.
