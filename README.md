# Olywork Plugins

Public plugin manifests, agent skills, and integration examples for Olywork.

This repository contains client-side integration assets only. The Olywork server,
credential handling, billing, catalog operations, and production infrastructure live
in the private core repository.

## License

Plugin source and examples are licensed under Apache-2.0. Provider names and logos
remain the property of their respective owners; see `ATTRIBUTIONS.md`.

## Development

Plugin packages are validated and built from the private Olywork core release process.
Contributions should not include credentials, private provider data, or server code.
